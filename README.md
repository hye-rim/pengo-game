# 펭고 🐧

추억의 오락실 펭고(Sega, 1982)를 본뜬 혼자 하는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 방향키/WASD 로 이동, **스페이스/Z/X** 로 블록 밀기(바로 앞이 벽이면 벽 흔들기). 폰은 왼쪽 패드 + 빨간 **밀기** 버튼.
- `P` 일시정지, `M` 소리.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙 (구현한 것)
- 얼음 블록을 밀면 막힐 때까지 미끄러지고, Sno-Bee 에 닿으면 으깹니다. 한 블록으로 여럿을 으깨면 400 · 1600 · 3200 · 6400점.
- 바로 뒤가 막힌 블록을 밀면 부서집니다(30점, 알 블록은 500점). 다이아몬드 블록은 안 부서집니다.
- 바깥 벽을 밀면 벽이 흔들려 붙어 있는 Sno-Bee 가 기절하고, 기절한 적은 밟으면 100점.
- 다이아몬드 블록 3개를 한 줄로 맞추면 10000점(벽에 붙여 맞추면 5000점, 한 번만), 모든 Sno-Bee 기절.
- 알 블록에서 Sno-Bee 가 깨어납니다(처음엔 동시에 3마리, 이후 4마리). 모두 처리하면 라운드 클리어 + 시간 보너스.
- 60초 넘게 못 끝내면 Sno-Bee 가 빨라지고, 120초 넘으면 얼음을 부수는 덩어리가 됩니다.

## 확인하지 못한 값 (제가 정한 값)
원작 자료 중 점수·시간 보너스 표는 공개 자료(arcade-history, 매뉴얼 요약)를 참고했지만, 아래는 확정하지 못해 제 판단으로 정했습니다.
- 미로 크기(13×15), 블록 배치(생성기로 라운드마다 만듦, 원작 판 그대로 아님), 16라운드까지의 알 수
- 시작 목숨 3, 추가 목숨 없음, 펭고·Sno-Bee 속도, 기절 시간(4.5초), 알이 다시 깨는 간격
- 그림·소리는 직접 그린/합성한 것입니다.
